# Prototype features

- Live speed awareness with calm, actionable nudges.
- Deterministic behaviour engine that converts safe driving into points and an improving safety score.
- Private trip history, safe-driving streak, and challenge progress.
- Eco-route comparison with safety and carbon estimates.
- Browser voice cues and nudge language selection (English, Hindi, Kannada).
- A privacy-safe community goal that shows only collective progress.
