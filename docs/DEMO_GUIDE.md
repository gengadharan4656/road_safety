# Demo guide

1. Start the server and open `/`.
2. On the dashboard, select **Start drive** to see live telemetry and a positive safety nudge.
3. Use the **Demo speed** controls to see the nudge adapt; speed at or under the limit earns safety points.
4. Open **Routes** to compare the seeded eco option against the quickest alternative.
5. Return to the dashboard to view private trips, challenges, reward balance, and the anonymous community goal.
